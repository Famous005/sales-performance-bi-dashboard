
# Sales Performance & Business Intelligence Dashboard

## Project Overview

This project analyses a fictional Nigerian retail company's
sales performance using Python, SQLite, SQL and Microsoft Power BI.

The dataset contains sales transactions recorded between
January and December 2025.

## Dataset Summary

| Metric | Value |
|---|---:|
| Sales transactions | 1,200 |
| Unique orders | 455 |
| Customers | 100 |
| Products | 25 |
| Regions | 6 |
| Total revenue | ₦615,491,675 |
| Units sold | 5,387 |
| Average order value | ₦1,352,728.96 |

## Key Business Findings

### Monthly Performance

- August generated the highest revenue: ₦80,801,875.
- June generated the second-highest revenue: ₦78,668,375.
- May recorded the highest month-over-month growth: 84.61%.

### Product Performance

- Laptop generated the highest revenue: ₦106,502,500.
- Projector ranked second: ₦103,117,500.
- Electronics is the leading product category.

### Customer Segmentation

- Consumer generated the highest revenue: ₦275,106,500.
- Small Business generated ₦184,842,500.
- Corporate generated ₦155,542,675.

### Regional Performance

- North East generated the highest revenue: ₦127,754,550.
- North West recorded the highest average order value:
  ₦1,611,482.89.

## Data Quality

The dataset passed the following checks:

- No missing required sales values.
- No duplicate transaction IDs.
- No invalid customer references.
- No invalid product references.
- No incorrect sales calculations.
- Every order belongs to one customer.
- Every order has one order date.
